# Work Card 01: Project Skeleton

## Goal

Scaffold the Vite + React + TypeScript app in this project folder, install Tailwind CSS and Framer Motion, wire in Google Fonts, set the correct title and package name, and confirm the dev server starts with the app name visible in the browser.

## Inputs

- `build-blueprint.md` — stack, folder structure, title, package name
- `architecture.md` — stack decision, file expectations
- `design.md` — Tailwind colour tokens, font choices

## Files likely touched

- `index.html` (title, Google Fonts link)
- `package.json` (name field)
- `vite.config.ts` (generated by scaffold)
- `tailwind.config.js` (custom tokens)
- `postcss.config.js` (generated)
- `tsconfig.json` (generated)
- `src/main.tsx` (entry point)
- `src/App.tsx` (placeholder header)
- `src/styles/tokens.css` (create — Tailwind base import + custom CSS vars)
- `src/styles/animations.css` (create — felt noise overlay keyframe)

## Instructions for the coding agent

### Step 1 — Scaffold without overwriting planning files

Run this command in the project root (the folder that contains `START_HERE.md`):

```bash
npx -y create-vite@9.2.1 app-temp --template react-ts --no-interactive
```

Do **not** cd into `app-temp`. Move everything inside `app-temp` (including hidden files like `.gitignore`) up to the project root:

```bash
mv app-temp/{.,}* . 2>/dev/null || true
rmdir app-temp
```

If the shell warns about moving `.` or `..`, that is safe to ignore. Confirm `START_HERE.md`, `prompts/`, `work-cards/`, and all planning `.md` files are still present.

**Never use `--overwrite` and never choose "Remove existing files"** — that would delete the planning files.

### Step 2 — Set title and package name

In `index.html`, set:
```html
<title>Tapau Card Game</title>
```

Add Google Fonts `<link>` tags in `<head>` **before** the title (use `display=swap`):
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Recoleta:wght@700&family=Inter:wght@400;600&display=swap" rel="stylesheet">
```

Note: If Recoleta is not available in Google Fonts at build time, use the fallback in CSS: `font-family: 'Cooper Black', serif`. Inter is always available.

In `package.json`, set `"name": "tapau-card-game"`.

### Step 3 — Install dependencies

```bash
npm install
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p
npm install framer-motion
```

### Step 4 — Configure Tailwind

In `tailwind.config.js`, set content paths and add custom theme tokens:

```js
/** @type {import('tailwindcss').Config} */
export default {
  content: ['./index.html', './src/**/*.{ts,tsx}'],
  theme: {
    extend: {
      colors: {
        felt: {
          DEFAULT: '#0C4A28',
          light: '#0F5C32',
          dark: '#0A3D20',
        },
        card: {
          DEFAULT: '#F0F4F1',
          border: '#D8DDD9',
          text: '#1A2E1F',
          muted: '#5A7A62',
        },
        emerald: {
          game: '#00A859',
        },
        chip: {
          scout: '#F59E0B',
          show: '#38BDF8',
        },
        score: {
          player: '#00A859',
          ai: '#F87171',
          round: '#FBBF24',
          turn: '#22D3EE',
        },
      },
      fontFamily: {
        display: ['Recoleta', 'Cooper Black', 'serif'],
        body: ['Inter', 'system-ui', 'sans-serif'],
      },
      borderRadius: {
        card: '12px',
        modal: '24px',
        pill: '9999px',
      },
    },
  },
  plugins: [],
}
```

### Step 5 — Create CSS files

Create `src/styles/tokens.css`:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;

:root {
  --felt: #0C4A28;
  --felt-light: #0F5C32;
  --felt-dark: #0A3D20;
  --card-face: #F0F4F1;
  --card-border: #D8DDD9;
  --emerald: #00A859;
  --chip-scout: #F59E0B;
  --chip-show: #38BDF8;
}

body {
  background-color: var(--felt);
  font-family: 'Inter', system-ui, sans-serif;
  color: #F0F4F1;
  min-height: 100dvh;
}
```

Create `src/styles/animations.css`:
```css
/* Felt noise overlay — applied to the root canvas */
.felt-noise::after {
  content: '';
  position: fixed;
  inset: 0;
  pointer-events: none;
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 200 200' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='noise'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.65' numOctaves='3' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23noise)' opacity='0.04'/%3E%3C/svg%3E");
  background-repeat: repeat;
  background-size: 200px 200px;
  z-index: 0;
}

@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.001ms !important;
    transition-duration: 0.001ms !important;
  }
}
```

### Step 6 — Update src/main.tsx

```tsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'
import './styles/tokens.css'
import './styles/animations.css'

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

### Step 7 — Replace src/App.tsx with placeholder

```tsx
function App() {
  return (
    <div className="felt-noise min-h-dvh bg-felt flex items-center justify-center">
      <h1 className="font-display text-5xl text-card">Tapau Card Game</h1>
    </div>
  )
}

export default App
```

### Step 8 — Remove Vite boilerplate

Delete `src/App.css` and `src/index.css` if they exist (the scaffold creates them; we use `tokens.css` instead).
Remove the import of `'./index.css'` from `main.tsx` if the scaffold added it.
Delete `src/assets/react.svg` and `public/vite.svg` if present — they are not needed.

### Step 9 — Start the dev server

```bash
npm run dev
```

Confirm no TypeScript errors in the terminal and the browser shows a dark green page with "Tapau Card Game" in a large serif font.

## What not to do

- Do not use `--overwrite` or choose "Remove existing files" in the scaffold step.
- Do not delete `START_HERE.md`, `prompts/`, `work-cards/`, or any planning `.md` file.
- Do not install any package other than those listed (no icon libraries, no state managers, no extra animation libs).
- Do not start building game components yet — that is Work Card 02.
- Do not add `localStorage` logic.
- Do not add `src/game/`, `src/state/`, or `src/components/` files yet — scaffold only.

8. Design check: the page background matches the felt green token from `design.md`; heading font is display serif, not sans-serif.
